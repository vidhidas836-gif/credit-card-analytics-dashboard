# Credit Card Analytics Dashboard

## Project Overview
This Power BI dashboard analyzes credit card data to provide insights into card distribution, credit limits, and card status.

## Tools Used
- Power BI
- Power Query

## KPIs
- Total Cards
- Active Cards
- Expired Cards
- Average Credit Limit

## Dashboard Features
- Card Type Distribution
- Card Network Analysis
- Card Status Analysis
- Interactive Slicers
- Credit Limit Analysis

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- Dashboard Design
- Data Visualization
